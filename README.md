# Meu Portfólio

Este projeto é um portfólio pessoal desenvolvido para apresentar meus trabalhos, habilidades e experiências profissionais.

## Tecnologias Utilizadas

### HTML5
Utilizado para estruturar o conteúdo das páginas do portfólio, garantindo uma base semântica e acessível.

### CSS3
Responsável pela estilização do site, proporcionando um layout moderno, responsivo e agradável visualmente.

### JavaScript
Adiciona interatividade ao portfólio, como animações, navegação dinâmica e manipulação de elementos na página.

### Frameworks/Bibliotecas

- **Bootstrap** : Auxilia na criação de layouts responsivos e componentes prontos para uso.

## Como Executar
1. Clone este repositório.
2. Abra o arquivo `index.html` em seu navegador ou utilize um servidor local para rodar o projeto.
